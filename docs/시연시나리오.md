# 시연 시나리오

녹화 대상은 로컬에서 실행한 Spring Boot 애플리케이션입니다. 조작 자동화로 실제 화면을 녹화하며 음성은 없습니다. 실제 결제나 배송은 진행하지 않습니다.

1. 메인에서 상품 목록과 페이지 이동을 확인합니다.
2. 회원가입 후 새 계정으로 로그인합니다.
3. 상품명 `머그`를 검색하고 카테고리 `주방`으로 필터링합니다.
4. 상품 상세에서 수량을 선택하고 장바구니에 담습니다.
5. 수량 변경 후 받는 분과 시연용 주소를 입력합니다.
6. 주문을 생성하고 주문번호·상품명·주문 당시 단가·합계를 확인합니다.
7. 주문내역에서 상세로 이동한 후 주문을 취소합니다.
8. 관리자 계정으로 로그인하고 새 상품을 등록합니다.
9. 상품 가격·재고를 수정하고 판매 중지 후 재개합니다.
10. 로그아웃하고 비로그인 상태의 장바구니 접근이 로그인을 요구하는지 확인합니다.

## 자동 검사

`mvn test`는 상품 화면 렌더링, 접근 제어·CSRF, 주문 금액·재고 차감, 취소 복원·중복 취소 거절, 재고 부족 롤백, 타인 주문 접근 거절, 가입 검증·해싱, 검색·수량 경계를 검사합니다.
