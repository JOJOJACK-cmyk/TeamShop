# 실제 팀 협업 진행 방법

이 저장소의 초기 작성은 한 계정에서 진행했습니다. 기능 브랜치나 여러 커밋만으로 팀원 간 협업을 증명할 수 없습니다.

## 권장 역할 분담

실제 팀원 명단을 확인한 후 담당자를 정합니다.

| 담당 영역 | 작업 예 | 브랜치 예시 |
| --- | --- | --- |
| 회원·보안 | 회원정보 수정, 입력 검증 보완 | feature/실제계정-member |
| 상품·관리자 | 상품 관리 테스트, 상품 정렬 | feature/실제계정-product |
| 장바구니·주문 | 동시 주문 검증, 주문 화면 개선 | feature/실제계정-order |

위 브랜치 이름은 예시이며 생성된 팀원 브랜치가 아닙니다.

## 각 팀원 작업

저장소 소유자가 실제 팀원을 collaborator로 추가합니다. 각 팀원은 자신의 계정과 Git 작성자 정보로 아래 작업을 수행합니다.

```bash
git clone https://github.com/JOJOJACK-cmyk/TeamShop.git
cd TeamShop
git switch -c feature/본인계정-담당기능
# 담당 기능을 수정하고 mvn test로 검증
git add .
git commit -m "feat: 담당 기능 구현"
git push -u origin feature/본인계정-담당기능
```

GitHub에서 main 대상 PR을 만들고 다른 팀원에게 리뷰를 요청합니다. 수정·리뷰 후 merge commit으로 병합하고 평가가 끝날 때까지 팀원 브랜치를 유지합니다. 커밋 작성자·날짜를 바꾸거나 수행하지 않은 리뷰를 기록하지 않습니다.

## 제출 전 확인

각 팀원의 실제 브랜치, 커밋 작성자, PR 변경 내역과 리뷰 이력이 남아 있는지 확인합니다. 최종 코드로 실행한 시연 영상을 제출하고 PPT 표지의 팀 번호·팀명·이름을 실제 정보로 바꿉니다.
